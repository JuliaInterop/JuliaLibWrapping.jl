# Concepts

The former all-in-one concepts page has been divided by purpose:

- [Architecture and metadata flow](@ref) explains the compiler, ABI metadata,
  optional API sidecar, and binding targets.
- [Building and distributing a library](@ref) covers `standard_build`,
  `build_library`, runtime bundles, and loading multiple libraries.
- [Generated Python bindings](@ref) describes `_lowlevel.py`, the editable
  façade, error conversion, and library loading.
- [Extending JuliaLibWrapping](@ref) documents `ABIInfo`, declaration ordering,
  carrier recognition, and the target extension interface.

This page remains as a signpost for links to the pre-0.2 documentation.
