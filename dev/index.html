JuliaLibWrapping

JuliaLibWrapping generates C headers and Python ctypes bindings for shared libraries compiled from Julia by juliac. It turns juliac ABI metadata into bindings for non-Julia callers.

New to the package? Start with the tutorial — it follows a small library from Julia source through pip install to a Python API using NumPy arrays.

The two-tool split

juliac / JuliaC.jl --emits--> JSON ABI-info file --consumed by--> JuliaLibWrapping --emits--> .h / Python package

JuliaC.jl compiles the shared library and emits a JSON file describing its ABI, but does not generate wrappers. JuliaLibWrapping consumes that JSON and emits the wrappers.

build_library runs both stages in one call when JuliaC.jl is loaded. See Concepts for details about the pipeline, bundling, loading multiple libraries in one process, and generated Python files.
